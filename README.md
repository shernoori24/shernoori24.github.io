# shernoori24.github.io

Portfolio personnel de Sheraqa NOORI, développeur IA, Data Science et Web.

## Aperçu

Ce site présente:
- Mon profil et mes compétences
- Mes expériences et ma formation
- Une galerie de projets avec modale détaillée
- Un formulaire de contact (Formspree)
- Un bouton fixe pour générer et télécharger le portfolio en PDF

## Stack

- HTML5
- CSS3
- JavaScript (vanilla)
- ScrollReveal
- Typed.js
- jsPDF

## Lancer en local

1. Cloner le dépôt.
2. Ouvrir le dossier dans VS Code.
3. Lancer avec un serveur local (Live Server par exemple).

## Structure

- index.html: page principale
- css/style.css: styles globaux et responsive
- js/script.js: interactions UI, animations, filtres, modale
- js/portfolio-pdf.js: génération du portfolio PDF

## Points techniques

- Design responsive desktop/mobile
- Optimisation SEO de base (meta tags, Open Graph, canonical)
- Accessibilité améliorée (labels de formulaire, préférences reduced motion)
